# Security policy

To report a security vulnerability, use [GitHub’s private vulnerability reporting form](https://github.com/UseMagicMtn/magicmtn/security/advisories/new). If the form is unavailable, email the maintainer at [rodrigo@magicmtn.ai](mailto:rodrigo@magicmtn.ai).

Include the MagicMtn version or commit, affected platform, impact, and steps to reproduce. Redact credentials, account data, and other sensitive details. Share the report privately before opening a public issue.
